# حكيم — سياسة قناة النتائج فقط

الغاية: تقليل عبء المستخدم بإرسال حالة التشغيل من الهاتف إلى قناة نتائج خاصة/شبه خاصة قابلة للفحص، دون تحويلها إلى قناة أوامر عامة.

- قناة النتائج OUTBOUND ONLY من الهاتف قدر الإمكان.
- لا تستقبل أو تنفذ أوامر تغيير من webhook عام.
- لا ترسل رموز الاقتران أو كلمات المرور أو المفاتيح أو tokens أو محتوى خاص غير لازم.
- أرسل فقط: request_id/status/phase/timestamp/result أو error مصفى/هوية نسخة عامة عند الحاجة.
- فشل قناة النتائج لا يوقف الوظيفة المحلية الأساسية.
- لا تعتبر وصول webhook دليل نجاح للمهمة؛ هو دليل نقل فقط.
- أي command relay خاص يبقى UNPROVEN حتى تأهيل أمني مستقل.
