# حكيم — نمط الاستقلال المجاني

هذا المسار يلغي اعتماد قناة الهاتف على Make أو أي مفتاح API مدفوع. الأوامر والنتائج تمر عبر ناقل قابل للاستبدال، وافتراضيًا يستخدم ntfy.sh المجاني. الناقل لا يرى محتوى الأمر أو النتيجة لأن المحتوى مشفّر طرفيًا.

## الثوابت
- لا Make ولا رصيد عمليات ولا مفتاح API.
- الأوامر HC1 والنتائج HR1 مشفرة بـ AES-256-GCM.
- مفتاح الاقتران يبقى محليًا على الهاتف ولا يُرسل كنص عبر الناقل.
- التنفيذ المحلي والخادم المحلي يبقيان داخل الجهاز.
- أي عملية تغيّر حالة الهاتف تبقى خلف موافقة Android صريحة.
- المضيف قابل للتبديل من رابط الاقتران، لذلك يمكن لاحقًا استبدال ntfy.sh بمضيف مملوك ذاتيًا دون تغيير قلب حكيم.

## حد تقني لا يمكن محوه
الوصول البعيد من ChatGPT إلى هاتف خلف شبكة الجوال يحتاج نقطة التقاء شبكية ما. هذا الإصدار يجعلها مجانية، بلا حساب، قابلة للاستبدال، ولا تحمل إلا نصًا مشفرًا.
